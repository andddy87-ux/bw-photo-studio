АЛГОРИТМЫ КОНВЕРТАЦИИ В Ч/Б
═══════════════════════════════════════════════════════════════

Простые математические:
  • Усреднение (Average): Y = (R+G+B)/3
  • Светлота (Lightness): Y = (max+min)/2
  • Яркость (Value/HSV): Y = max(R,G,B)
  • Один канал: только R, только G, только B

Перцептивные (учитывают физиологию зрения):
  • Rec. 601 (SDTV): 0.299R + 0.587G + 0.114B
  • Rec. 709 (HDTV/sRGB): 0.2126R + 0.7152G + 0.0722B
  • Rec. 2100 (HDR): 0.2627R + 0.6780G + 0.0593B

Продвинутые и художественные:
  • Микширование каналов с пресетами фильтров:
    - Красный фильтр (затемняет небо)
    - Жёлтый фильтр (умеренный эффект)
    - Зелёный фильтр (светлая листва)
    - Синий фильтр (светлое небо)
    - ИК-пресет и другие
  • CIE Lab (L-канал) — чистая яркость
  • Адаптивный (Decolorize) — сохранение локального контраста

═══════════════════════════════════════════════════════════════
РЕДАКТИРОВАНИЕ Ч/Б
═══════════════════════════════════════════════════════════════

Тон:
  • Яркость / Контраст
  • Уровни (Levels) — точки чёрного/белого, гамма
  • Кривые тонов (5 контрольных точек)
  • Эквализация гистограммы
  • CLAHE (адаптивная эквализация)

Детали:
  • Нерезкое маскирование (USM)
  • Усиление локального контраста (Clarity)

Шумоподавление:
  • NLMeans (нелокальные средние) — лучший результат
  • Билатеральный фильтр
  • Гауссов фильтр
  • Медианный фильтр

Художественные:
  • Виньетка
  • Плёночная зернистость
  • Раздельное тонирование (Split Toning)

Геометрия:
  • Поворот (произвольный угол)
  • Отражение (горизонтальное/вертикальное)

ИНФРАКРАСНАЯ ФОТОГРАФИЯ
═══════════════════════════════════════════════════════════════

Конвертация ИК-снимков:
  • R↔B Обмен каналов (для конвертированных ИК-камер)
  • Красный канал → Ч/Б
  • Ложноцветный → Ч/Б
  • Ручной микс каналов (настройка под конкретный фильтр)

Симуляция ИК-фильтров:
  • 590nm (мягкий «золотой» ИК)
  • 720nm (R72 — самый популярный фильтр)
  • 850nm (жёсткий дальний ИК)
  • Эффект Вуда (Wood Effect)

Художественные эффекты:
  • Высокий контраст
  • Мечтательный ореол (Halation)
  • Bleach Bypass (кинематографический)

Тонирование ИК:
  • Тёплое (имитация Kodak HIE)
  • Лунное (холодное)
  • Цианотипия

Проблема: "rawpy не установлен"
Решение: pip install rawpy

Проблема: "pillow-heif не установлен"
Решение: pip install pillow-heif

Проблема: Приложение не запускается
Решение: Запустите install.bat заново, проверьте версию Python (3.10+)

Проблема: Медленная загрузка NEF
Пояснение: 14-bit RAW требует демозаикинга (~2-5 сек для 24 Мп)
